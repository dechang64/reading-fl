### 三、联邦学习：开放中的隐私守门人

但开放不等于裸奔。

当更多人参与科研，数据隐私问题更加尖锐。一个人用AI分析健康数据、阅读行为、消费习惯——这些数据谁来看？怎么保证不被滥用？

联邦学习（Federated Learning）是这个问题的技术解：

- **数据不动模型动**：你的数据留在本地，只有模型参数上传
- **差分隐私保护**：即使拿到参数，也无法反推原始数据
- **多方协作不互窥**：多个OPC可以联合训练模型，但彼此看不到对方数据

在我们的Reading-FL原型中，FedAvg已经达到85.5%的准确率——这意味着读者可以在不暴露阅读数据的前提下，获得个性化的阅读推荐和情感匹配。

**开放和隐私不是矛盾，联邦学习让它们同时成立。**

### 项目一：本地联邦学习情感分析（入门级）

**目标**：用FedAvg训练一个文本情感分类器，数据不出本地

**技术栈**：Python + PyTorch + Flower框架

```python
# fl_client.py - 联邦学习客户端
import flwr as fl
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

class SentimentClient(fl.client.NumPyClient):
    def __init__(self, model, train_loader, val_loader):
        self.model = model
        self.train_loader = train_loader
        self.val_loader = val_loader

    def get_parameters(self, config):
        return [val.cpu().numpy() for val in self.model.state_dict().values()]

    def set_parameters(self, parameters):
        params_dict = zip(self.model.state_dict().keys(), parameters)
        state_dict = {k: torch.tensor(v) for k, v in params_dict}
        self.model.load_state_dict(state_dict, strict=True)

    def fit(self, parameters, config):
        self.set_parameters(parameters)
        # 本地训练 - 数据不离开此设备
        optimizer = torch.optim.AdamW(self.model.parameters(), lr=2e-5)
        self.model.train()
        for batch in self.train_loader:
            outputs = self.model(**batch)
            loss = outputs.loss
            loss.backward()
            optimizer.step()
            optimizer.zero_grad()
        return self.get_parameters(config={}), len(self.train_loader.dataset), {}

    def evaluate(self, parameters, config):
        self.set_parameters(parameters)
        self.model.eval()
        loss, correct = 0, 0
        with torch.no_grad():
            for batch in self.val_loader:
                outputs = self.model(**batch)
                loss += outputs.loss.item()
                correct += (outputs.logits.argmax(-1) == batch["labels"]).sum()
        accuracy = correct / len(self.val_loader.dataset)
        return loss, len(self.val_loader.dataset), {"accuracy": accuracy}

# 启动客户端
model = AutoModelForSequenceClassification.from_pretrained(
    "bert-base-chinese", num_labels=2
)
fl.client.start_client(
    server_address="localhost:8080",
    client=SentimentClient(model, train_loader, val_loader)
)
```

**关键点**：
- `get_parameters()` 只上传模型参数，不上传数据
- `fit()` 在本地训练，数据不离开设备
- FedAvg聚合时按样本数加权（不是简单平均！）

### 项目三：联邦学习隐私阅读推荐（高级）

**目标**：Reading-FL原型——读者数据不出本地，获得个性化推荐

**核心架构**：
```
读者A（本地模型）──┐
读者B（本地模型）──┼→ 聚合服务器（FedAvg加权）→ 全局模型 → 个性化推荐
读者C（本地模型）──┘
```

**FedAvg加权聚合（关键！）**：
```python
def fedavg_aggregate(params_list, client_data_sizes):
    """标准FedAvg：按样本数加权，不是简单平均"""
    total_samples = sum(client_data_sizes)
    weights = [n / total_samples for n in client_data_sizes]

    aggregated = []
    for layer_params in zip(*params_list):
        weighted_sum = sum(
            w * torch.tensor(p)
            for w, p in zip(weights, layer_params)
        )
        aggregated.append(weighted_sum)
    return aggregated
```

**注意**：很多开源实现用`.mean(dim=0)`代替加权，这是错的！FedAvg原论文明确要求按样本数加权。我们审计了6个项目，全部犯了这个错误。
