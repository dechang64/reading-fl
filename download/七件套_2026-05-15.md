### 正文：

昨天，2026世界数字教育大会发布了6项科学智能成果。其中最让我睡不着觉的，不是什么大模型又刷了什么benchmark，而是一个叫DeepScientist的系统。

它不是帮你查文献的AI。不是帮你润色论文的AI。它是一个**全自动闭环工作的"AI科研专家"**——自主思考、编写代码、执行实验、分析结果、迭代假设。依托"研究图谱"和"科研长程记忆"，它能基于经验积累不断改进实验策略。

换句话说，它做的事情，跟一个博士生做的，越来越像了。

---

**66%：一个让学术界沉默的数字**

几乎同一时间，斯坦福大学发布了《2026年AI指数报告》。423页，数据驱动，不带感情色彩。但其中一组数据让整个学术界沉默了：

AI智能体处理现实世界计算机任务的成功率，从18个月前的**12%**跃升至2026年3月的**66%**。距离人类表现仅差6个百分点。

18个月。从12%到66%。这不是线性增长，这是指数级跃迁。

网络安全任务上，AI智能体解决问题的成功率提升更加惊人。报告还指出，中美顶尖模型的性能差距已经缩小到**2.7%**。

这些数字意味着什么？意味着AI已经不再是一个"需要人类监督才能工作"的工具了。它正在变成一个可以独立完成复杂任务的"同事"。

---

**教授的焦虑，不是失业，是重新定义**

作为一个在大学里教了十几年书的人，我最近经常被学生问一个问题："老师，AI都能做科研了，我们学这些还有什么用？"

我的回答是：这个问题问反了。

AI能做科研，恰恰说明**科研的价值从未如此重要**。DeepScientist能设计实验、跑数据、写代码，但它不能决定"为什么这个问题值得研究"。它不能在深夜的实验室里突然灵光一闪，发现一个前人从未想到的角度。它不能在学术会议上跟同行争论到面红耳赤，然后第二天早上意识到对方说得对。

AI做的是"how"，人类做的是"why"。

但我也必须诚实地说：这个边界正在变得模糊。而且模糊的速度比我预想的快得多。

---

**OPC的视角：当科研民主化**

从OPC（Open Platform Creator）的角度看，AI科研专家的出现有一个更深层的含义：**科研正在民主化**。

过去，做科研需要：博士学位、实验室、经费、导师、人脉。现在，一个有想法的本科生，借助DeepScientist这样的系统，可能就能完成过去需要一个团队才能完成的研究。

这不是威胁。这是机会。

OPC的核心信念就是：**创造力的门槛应该被降低，而不是被抬高**。AI科研工具的出现，让这个信念在学术领域第一次有了技术支撑。

**1. 评估体系严重滞后**

报告提出了一个新概念："AI Sovereignty"（人工智能主权）。各国不再仅仅关注AI监管，而是将AI能力视为国家主权的一部分。这对学术界的国际合作意味着什么？值得深思。

**3. 科研范式正在被重写**

DeepScientist的出现不是"多了一个工具"，而是科研范式的转变。过去是"人类提出假设→设计实验→收集数据→验证"，现在AI可以参与甚至主导中间的每一步。这意味着科研的瓶颈从"执行能力"转移到了"问题定义能力"。

---

**OPC视角：联邦学习是关键基础设施**

DeepScientist需要大量数据来训练和验证。如果所有数据都集中到少数几个平台，那么科研民主化就是一句空话——你用的AI科研工具，背后是别人的数据垄断。

联邦学习的价值在于：**让AI在数据不离开本地的前提下完成训练**。这意味着每个研究者、每个实验室、每个大学都能保留自己的数据主权，同时享受AI科研工具的能力。

这也是我们团队开发Reading-FL、Embodied-FL、Organoid-FL等项目的初衷：不是炫技，而是为未来的AI科研生态提供隐私保护的基础设施。

## 架构推测：闭环科研Agent

虽然DeepScientist的详细技术文档尚未公开，但根据其描述的功能，可以推测其核心架构包含以下模块：

```
┌─────────────────────────────────────────┐
│              DeepScientist              │
├─────────────────────────────────────────┤
│  ┌──────────┐    ┌──────────────────┐   │
│  │ 假设生成器 │───→│ 实验规划引擎     │   │
│  └──────────┘    └──────────────────┘   │
│       ↑                    ↓             │
│  ┌──────────┐    ┌──────────────────┐   │
│  │ 迭代优化器 │←──│ 结果分析模块     │   │
│  └──────────┘    └──────────────────┘   │
│       ↑                    ↓             │
│  ┌──────────┐    ┌──────────────────┐   │
│  │ 长程记忆库 │←──│ 代码执行沙箱     │   │
│  └──────────┘    └──────────────────┘   │
│       ↑                                  │
│  ┌──────────┐                           │
│  │ 研究图谱  │                           │
│  └──────────┘                           │
└─────────────────────────────────────────┘
```

**关键设计点：**

1. **长程记忆（Long-term Memory）**：这是DeepScientist区别于普通Agent的核心。普通Agent的上下文窗口有限，而科研需要跨实验、跨周期的经验积累。推测其使用了向量数据库（如HNSW索引）+ 结构化知识图谱的组合方案。

2. **研究图谱（Research Graph）**：将科研文献、实验结果、假设关系构建为图谱，支持推理和知识发现。这与我们团队在Embodied-FL项目中使用的HNSW任务相似度聚合有异曲同工之妙。

3. **闭环反馈（Closed-loop Feedback）**：假设→实验→分析→迭代的闭环，本质是一个强化学习过程。每一次实验的结果都作为反馈信号，优化下一次假设的质量。

---

## 联邦学习结合的可能性

DeepScientist面临一个核心挑战：**数据隐私**。

科研数据往往包含敏感信息（患者数据、企业数据、国防数据）。如果DeepScientist需要集中所有数据才能工作，那么它的应用场景将大打折扣。

**联邦学习可以解决这个问题：**

```python
# 联邦科研Agent的概念架构
class FederatedResearchAgent:
    def __init__(self):
        self.local_hypothesis = HypothesisGenerator()
        self.local_executor = ExperimentExecutor()
        self.global_aggregator = FedAvgAggregator()
    
    def local_step(self, data):
        """本地：在私有数据上生成假设并验证"""
        hypothesis = self.local_hypothesis.generate(data)
        result = self.local_executor.run(hypothesis, data)
        return self.encode_experience(hypothesis, result)
    
    def global_aggregate(self, local_experiences):
        """全局：聚合多方的科研经验（不共享原始数据）"""
        return self.global_aggregator.aggregate(local_experiences)
```

这种架构下：
- 每个实验室的数据不离开本地
- 科研经验（假设-结果对）通过联邦聚合共享
- 全局模型在保护隐私的前提下持续进化

翻译成人话就是：AI已经跑得比我们快了，但我们连它跑到哪里了都看不清楚。

这在学术界尤其危险。

我们评价一个研究生的标准是什么？发了多少论文？影响因子多少？引用次数多少？这些标准，AI可能很快就能达到甚至超越。

那我们评价一个教授的标准是什么？拿了多少项目？带了多少学生？这些标准，在AI科研时代，可能也需要重新定义。

**我的学生在问一个我答不上来的问题**

最近经常有学生问我："老师，AI都能做科研了，我们学这些还有什么用？"

我通常会给一个"正确"的答案：AI做的是HOW，人类做的是WHY。AI能帮你跑实验，但不能告诉你为什么这个问题值得研究。

但说实话，这个答案我自己都不太信了。

因为DeepScientist的"研究图谱"和"科研长程记忆"，本质上就是在学习"为什么这个问题值得研究"。它可能现在还做不到，但18个月前，它连跑个实验都做不到。

---

**所以，我想认真聊聊OPC**

OPC是Open Platform Creator的缩写，翻译过来是"开放创造平台"。

这个理念的核心很简单：AI时代的创造力，不应该被少数人垄断。

DeepScientist的出现，让科研的门槛正在降低。以前你需要一个完整的实验室、一笔经费、一个导师团队，才能做像样的研究。现在，一个有想法的本科生，借助AI工具，可能就能完成过去需要一个团队才能做的事。

这不是威胁。这是机会。

但前提是，这些AI工具必须是开放的、可及的、保护隐私的。如果所有的AI科研能力都集中在几家大公司手里，那科研民主化就是一句空话。

这就是为什么我一直做联邦学习的研究。联邦学习的核心思想是：数据不离开本地，模型在多方之间协作训练。这意味着每个研究者、每个实验室、每个大学，都能保留自己的数据主权，同时享受AI科研工具的能力。

我带的学生做的Reading-FL项目，就是这个思路的一个小尝试：用联邦学习保护读者的阅读数据隐私，同时让AI更好地理解每个人的阅读偏好。
