**四、联邦学习：OPC科技工作者的隐私基础设施**

作为OPC科技工作者，你面临的不仅是"算不算"的问题，还有"怎么保护数据"的问题。

你的用户数据、你的模型训练、你的商业机密——在一个人+AI的模式下，数据安全全靠你自己。

联邦学习（Federated Learning）是解决这个问题的技术路径：

- **数据不出域**：用户数据留在本地，只上传模型参数
- **隐私可证**：从技术层面保证合规，不用靠承诺
- **协作可能**：多个OPC可以联合训练模型，不暴露各自数据

```python
# OPC联邦学习聚合示例
def fedavg_aggregate(client_params, client_data_sizes):
    """标准FedAvg加权聚合"""
    total = sum(client_data_sizes)
    if total == 0:
        raise ValueError("No data available for aggregation")
    global_params = torch.zeros_like(client_params[0])
    for params, size in zip(client_params, client_data_sizes):
        weight = size / total
        global_params += weight * params
    return global_params
```

这不是理论——这是Reading-FL项目正在做的事：让阅读社区的用户在不暴露阅读数据的前提下，获得个性化推荐。

**实战代码：OPC联邦学习聚合器**

```python
import torch
from typing import List, Optional

class OPCFedAvgAggregator:
    """OPC联邦学习聚合器 - 标准FedAvg加权聚合"""

    def __init__(self, min_clients: int = 2):
        self.min_clients = min_clients

    def aggregate(
        self,
        client_params: List[torch.Tensor],
        client_data_sizes: Optional[List[int]] = None
    ) -> torch.Tensor:
        """
        加权联邦平均聚合

        Args:
            client_params: 各客户端模型参数列表
            client_data_sizes: 各客户端数据量（None时等权）

        Returns:
            聚合后的全局模型参数

        Raises:
            ValueError: 客户端数量不足或数据量为零
        """
        if len(client_params) < self.min_clients:
            raise ValueError(
                f"需要至少{self.min_clients}个客户端，当前{len(client_params)}个"
            )

        if client_data_sizes is None:
            # 等权聚合（退化为简单平均）
            return torch.stack(client_params).mean(dim=0)

        total_data = sum(client_data_sizes)
        if total_data == 0:
            raise ValueError("总数据量为零，无法进行加权聚合")

        # 标准FedAvg: w_global = Σ(n_k/N) * w_k
        global_params = torch.zeros_like(client_params[0])
        for params, size in zip(client_params, client_data_sizes):
            weight = size / total_data
            global_params += weight * params

        return global_params
```
