### 信号一：平台开始"去水"

微信公众号的打击目标很明确——"低价值AIGC内容"。

注意关键词：**低价值**。

不是打击所有AI辅助创作，是打击那些用AI批量生成、没有原创思考、没有个人观点、对读者没有实际价值的内容。

什么是"低价值AIGC"？我观察了一下被限流的内容类型：

- AI生成的"干货合集"——把网上已有的信息重新排列组合，没有增量
- AI生成的"情感鸡汤"——千篇一律的句式，没有真实经历
- AI生成的"新闻搬运"——把新闻改写一遍就发，没有分析
- AI生成的"伪原创"——同一篇文章换个说法发三遍

这些内容的共同特征是：**AI做了100%，人做了0%。**

### 信号二：法律开始"划线"

AI搜索版权侵权案的终审判决，为AI内容领域划了一条重要的线。

虽然判决细节尚未完全公开，但核心争议很清楚：AI搜索引擎在生成回答时，是否侵犯了原始内容创作者的版权？

这个判决的意义不在于"AI能不能用别人的内容"，而在于"AI用别人的内容时，创作者的权益如何保障"。

对OPC创作者来说，这条线既是约束也是保护——约束你不能随意抓取他人内容，保护你自己的原创内容不被AI随意"消化"。

下架万部，不是"打击AI短剧"，是"淘汰劣质内容"。

这和微信公众号的打击逻辑一致：**不是AI的错，是用AI的人的错。**

**AI做30%，人做70%。**

你提供原创观点、真实经历、个人判断——这是70%。

AI是工具，不是作者。工具的价值取决于使用它的人。

OPC（Open Platform Creator）的核心就是这种关系：一个人，用AI工具，创造有价值的内容。AI放大你的能力，但不替代你的判断。

### 一、平台到底在打击什么？

微信公众号的官方说法是"非真人自动化创作"和"低价值AIGC内容"。

这两个词需要拆开理解。

**"非真人自动化创作"**：指的是完全由AI生成、没有人类实质性参与的内容。典型特征：
- 批量生产（一天发10篇以上）
- 内容同质化（同一模板换个关键词）
- 缺乏原创观点（只是信息的重新排列）
- 没有个人风格（读不出是谁写的）

**"低价值AIGC"**：指的是对读者没有实际价值的内容。典型特征：
- 信息密度低（3000字只说了1个常识）
- 没有增量（网上已有100篇类似文章）
- 没有可操作性（读完不知道该做什么）
- 情感空洞（AI生成的"鸡汤"没有真实经历支撑）

**关键判断标准：如果去掉AI的部分，内容还剩多少价值？**

如果答案是"几乎没了"，那就是打击目标。
如果答案是"核心观点和经历都在"，那就是安全的。

---

### 二、AI搜索版权案的启示

国内首起AI搜索版权侵权案的终审判决，虽然细节尚未完全公开，但核心争议很明确：

**AI搜索引擎在生成回答时，引用了原创内容，是否构成侵权？**

这个判决对OPC创作者有两层启示：

**第一层：约束。** 你用AI辅助创作时，不能直接让AI"改写"别人的文章然后当自己的发。这不只是道德问题，现在是法律问题。

**第二层：保护。** 这个判决也意味着，你的原创内容受到版权保护。如果AI搜索引擎在未经授权的情况下大量引用你的内容，你有法律依据维权。

**实操建议：**
- AI辅助创作时，让AI帮你"整理框架"和"优化表达"，不要让AI"改写他人文章"
- 如果引用他人内容，注明来源
- 保留创作过程的记录（草稿、修改痕迹），证明人类实质性参与

---

### 三、OPC vs 纯AIGC：本质区别

很多人把OPC和"用AI批量生产内容"混为一谈。这是误解。

| 维度 | 纯AIGC（被打击） | OPC（被鼓励） |
|------|-----------------|--------------|
| 创作主体 | AI为主，人为辅 | 人为主，AI为辅 |
| 原创性 | 低（信息重组） | 高（原创观点+经历） |
| 价值密度 | 低（3000字=1个常识） | 高（3000字=1个洞察） |
| 个人风格 | 无（读不出是谁写的） | 有（独特的表达方式） |
| 生产方式 | 批量自动化 | 精品化+AI提效 |
| AI的角色 | 替代人类 | 放大人类能力 |

OPC的核心公式：**人的专业能力 × AI的效率工具 = 高价值内容**

AI做的是"放大器"，不是"替代品"。

### 二、AI供应链的攻击面

传统软件供应链的攻击面已经足够复杂（依赖投毒、Typosquatting、供应链劫持），AI供应链在此基础上增加了新的维度：

**1. 模型供应链**

- 预训练模型可能包含恶意嵌入（后门攻击）
- Hugging Face等模型仓库的模型可能被投毒
- 模型权重文件可能被篡改

**2. 数据供应链**

- 训练数据可能被注入恶意样本（数据投毒）
- 数据标注服务可能被劫持
- 数据增强工具可能引入偏差

**3. 框架/工具供应链**

- AI框架本身可能有漏洞（如本次OpenClaw事件）
- Python包的依赖链可能引入不安全的传递依赖
- API密钥可能被硬编码在开源项目中

**4. 推理供应链**

- 模型服务API可能被劫持
- 推理结果可能被篡改（模型窃取攻击）
- 日志中可能泄露敏感信息

### 三、依赖审计脚本

以下是一个Python脚本，用于审计项目的依赖安全性：

```python
#!/usr/bin/env python3
"""
AI项目依赖安全审计工具
检查：过期依赖、已知漏洞、传递依赖风险、硬编码密钥
"""

import subprocess
import json
import re
import sys
from pathlib import Path
from typing import Dict, List, Tuple


def get_installed_packages() -> Dict[str, str]:
    """获取已安装的包及其版本"""
    result = subprocess.run(
        ["pip", "list", "--format=json"],
        capture_output=True, text=True
    )
    packages = {}
    for pkg in json.loads(result.stdout):
        packages[pkg["name"].lower()] = pkg["version"]
    return packages


def check_outdated(packages: Dict[str, str]) -> List[Tuple[str, str, str]]:
    """检查过期依赖"""
    result = subprocess.run(
        ["pip", "list", "--outdated", "--format=json"],
        capture_output=True, text=True
    )
    outdated = []
    for pkg in json.loads(result.stdout):
        outdated.append((
            pkg["name"],
            pkg["version"],
            pkg["latest_version"]
        ))
    return outdated


def scan_hardcoded_secrets(project_dir: str) -> List[Tuple[str, int, str]]:
    """扫描硬编码的密钥和Token"""
    patterns = [
        (r'api[_-]?key\s*=\s*["\']([^"\']+)["\']', "API Key"),
        (r'secret[_-]?key\s*=\s*["\']([^"\']+)["\']', "Secret Key"),
        (r'token\s*=\s*["\']([^"\']{20,})["\']', "Token"),
        (r'password\s*=\s*["\']([^"\']+)["\']', "Password"),
        (r'Bearer\s+([a-zA-Z0-9\-_]+\.){2}', "Bearer Token"),
    ]
    
    findings = []
    project_path = Path(project_dir)
    
    for py_file in project_path.rglob("*.py"):
        if ".venv" in str(py_file) or "node_modules" in str(py_file):
            continue
        content = py_file.read_text(errors="ignore")
        for pattern, label in patterns:
            for match in re.finditer(pattern, content, re.IGNORECASE):
                line_num = content[:match.start()].count('\n') + 1
                findings.append((
                    str(py_file.relative_to(project_path)),
                    line_num,
                    label
                ))
    
    return findings


def check_pip_audit() -> List[Dict]:
    """使用pip-audit检查已知漏洞"""
    try:
        result = subprocess.run(
            ["pip-audit", "--format=json"],
            capture_output=True, text=True
        )
        if result.returncode == 0:
            return []
        return json.loads(result.stdout)
    except FileNotFoundError:
        print("⚠️  pip-audit未安装，跳过漏洞检查")
        print("   安装: pip install pip-audit")
        return []


def audit(project_dir: str = "."):
    """执行完整审计"""
    print("=" * 60)
    print("AI项目依赖安全审计")
    print("=" * 60)
    
    # 1. 已安装包
    packages = get_installed_packages()
    print(f"\n📦 已安装包: {len(packages)}个")
    
    # 2. 过期依赖
    outdated = check_outdated(packages)
    if outdated:
        print(f"\n⚠️  过期依赖: {len(outdated)}个")
        for name, current, latest in outdated[:10]:
            print(f"   {name}: {current} → {latest}")
        if len(outdated) > 10:
            print(f"   ...还有{len(outdated)-10}个")
    else:
        print("\n✅ 所有依赖均为最新版本")
    
    # 3. 已知漏洞
    vulns = check_pip_audit()
    if vulns:
        print(f"\n🔴 已知漏洞: {len(vulns)}个")
        for v in vulns[:10]:
            name = v.get("name", "unknown")
            desc = v.get("description", "")[:80]
            print(f"   {name}: {desc}")
    else:
        print("\n✅ 未发现已知漏洞")
    
    # 4. 硬编码密钥
    secrets = scan_hardcoded_secrets(project_dir)
    if secrets:
        print(f"\n🔴 硬编码密钥: {len(secrets)}处")
        for file, line, label in secrets[:10]:
            print(f"   {file}:{line} - {label}")
    else:
        print("\n✅ 未发现硬编码密钥")
    
    # 5. 总结
    print("\n" + "=" * 60)
    issues = len(outdated) + len(vulns) + len(secrets)
    if issues == 0:
        print("✅ 审计通过，未发现安全问题")
    else:
        print(f"⚠️  发现{issues}个问题，建议修复")
    print("=" * 60)


if __name__ == "__main__":
    project_dir = sys.argv[1] if len(sys.argv) > 1 else "."
    audit(project_dir)
```

使用方法：

```bash

pip install pip-audit

# 运行审计
python audit_deps.py /path/to/your/project
```

### 四、联邦学习与本地化部署的安全优势

在AI供应链安全日益受到关注的背景下，联邦学习和本地化部署的安全优势变得更加突出。

**传统集中式AI的安全风险：**
- 模型托管在云端，依赖云服务商的安全措施
- 数据传输过程中可能被截获
- API密钥泄露影响范围大
- 第三方依赖的漏洞影响所有用户

**联邦学习+本地化部署的安全优势：**
- 模型在本地运行，不依赖外部推理服务
- 数据不离开设备，消除传输风险
- 依赖链更短，攻击面更小
- 即使框架有漏洞，影响范围限于本地

我们在实验室的实践（Reading-FL、EWA-Fed等项目）中，所有模型训练和推理都在本地完成。联邦聚合只传输模型梯度，不传输原始数据。

这种架构天然具有更强的供应链安全属性。

但AI不知道为什么今天要给那个穿灰色大衣的老人多加一份糖——因为那个老人每次来都点同样的咖啡，但今天他的眼神比平时更疲惫。

AI不知道为什么要在下雨天放爵士乐——因为下雨天人们需要一点温暖的声音，而爵士乐刚好。

AI不知道为什么要在那个大学生考试前给他免费加一块蛋糕——因为他看起来很紧张，一块蛋糕可能不会改变什么，但至少让他知道有人在乎。

Erik说，这些事情，数据里没有。算法算不出来。只有一个人，每天在这里，看着来来往往的人，才能知道。

---

### 一个人

我后来把Erik的故事讲给很多人听。

有人说，这就是AI的局限——它没有同理心。
有人说，这只是情怀——AI早晚会学会这些。
有人说，这是杞人忧天——AI咖啡馆和人类咖啡馆可以共存。

我觉得都对，但都不完全对。

我想说的是另一件事：**一个人，认真做一件事，这件事本身就有价值。**

Erik每天在Fika站十二个小时。他不是最聪明的咖啡师，不是最有创意的咖啡师，可能也不是技术最好的咖啡师。

但他每天在这里。他认识每一个常客。他知道谁喜欢多加糖，谁喜欢少加奶，谁考试前会紧张，谁失恋了需要安慰。

这些事情，AI可以学，但需要时间。而Erik已经做了十五年。

---

### 母亲节

今天是母亲节。

我本来想写一篇关于AI内容治理的技术分析——微信公众号打击低价值AIGC、AI搜索版权案、红果短剧下架。这些事情确实很重要，也确实值得聊。

但今天早上醒来，我想到的不是这些。

我想到的是我妈。

我妈不会用AI。她连微信语音都是我教了好几遍才学会的。她不知道什么是OPC，不知道什么是联邦学习，不知道什么是AIGC著作权。

但她知道一件事：她儿子在苏州读书，每周四晚上八点会接她的电话。

她不知道我在写什么文章，不知道我在做什么项目，不知道我在维护几个GitHub仓库。

但她知道：她儿子在认真做一件事。

这就够了。

---

### AI和人的距离

回到Andon Labs。

后来我问那个工程师，你们觉得AI咖啡馆最终会取代人类咖啡馆吗？

他想了很久，说：

"I don't think AI will replace human cafes. I think AI will make human cafes better."

他说，Andon Labs的存在不是为了证明"AI可以开咖啡馆"，而是为了证明"AI可以帮助咖啡馆做得更好"。

他们正在把Andon Labs开发的技术开源——温度控制系统、需求预测算法、客户分析工具。任何人类咖啡馆都可以免费使用。

Erik可以用AI来预测明天需要多少咖啡豆，但他仍然会亲手做每一杯咖啡。

AI帮他省下算账和采购的时间，让他有更多精力做他最擅长的事——认识每一个走进来的人。

---

### 一个人+AI

这就是OPC。

OPC不是"AI替代人类"。OPC是"AI帮助一个人做到以前做不到的事"。

Erik一个人开一家咖啡馆，以前需要雇三个人。现在有了AI工具，他一个人就能管理采购、库存、客户分析。

但他仍然每天站在吧台后面，亲手做每一杯咖啡。

AI帮他省时间，他用手省下来的时间做AI做不到的事。

一个人+AI。

不是一个人被AI替代，是一个人被AI放大。

---

### 今天

今天是母亲节。

如果你在妈妈身边，放下手机，陪她坐一个下午。

如果你不在妈妈身边，给她打个电话。就说"妈，母亲节快乐，我想你了"。

她可能会说"过什么节"。

但你听出来了吗——她说"过什么节"的时候，嘴角是往上翘的。

今天不聊AI，不聊技术，不聊OPC。

就聊一件事：你妈妈。
