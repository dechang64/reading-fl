## 三、联邦学习：AI员工之间的"工会"

传统OPC的痛点：每个AI工具独立运行，数据不互通，经验不共享。

联邦学习的解决方案：

```python
# Reading-FL: OPC多AI协作的联邦聚合
class OPCFedAvgAggregator:
    """OPC场景下的联邦平均聚合器"""

    def aggregate(self, client_updates, client_weights):
        """
        加权聚合多个AI员工的学习成果
        - client_updates: 各AI的模型更新
        - client_weights: 各AI的数据量权重
        """
        total = sum(client_weights)
        if total == 0:
            raise ValueError("总权重为零，无法聚合")

        global_update = torch.zeros_like(client_updates[0])
        for update, weight in zip(client_updates, client_weights):
            global_update += (weight / total) * update

        return global_update
```

核心思想：**AI员工不需要共享原始数据，只需要共享学习成果。** 就像员工不需要把日记本交给公司，只需要在周会上分享经验。

## 二、联邦聚合器的实现

智博会的"机器人小镇"隐喻了多AI协作：搬货机器人需要和巡检机器人共享环境信息。在OPC场景下，这就是联邦学习。

```python
import torch
from typing import List, Optional

class OPCFedAvgAggregator:
    """
    OPC联邦平均聚合器
    支持样本数加权，兼容等权回退
    """

    def __init__(self, min_clients: int = 2):
        self.min_clients = min_clients

    def aggregate(
        self,
        params_list: List[torch.Tensor],
        client_data_sizes: Optional[List[int]] = None
    ) -> torch.Tensor:
        """
        FedAvg加权聚合

        Args:
            params_list: 各客户端模型参数列表
            client_data_sizes: 各客户端数据量（用于加权）
                              None时退化为等权平均

        Returns:
            聚合后的全局模型参数

        Raises:
            ValueError: 客户端数量不足或总权重为零
        """
        if len(params_list) < self.min_clients:
            raise ValueError(
                f"客户端数量{len(params_list)}不足最低要求{self.min_clients}"
            )

        if client_data_sizes is None:
            # 等权回退
            return torch.stack(params_list).mean(dim=0)

        total = sum(client_data_sizes)
        if total == 0:
            raise ValueError("总数据量为零，无法进行加权聚合")

        weights = [size / total for size in client_data_sizes]
        result = torch.zeros_like(params_list[0])
        for params, weight in zip(params_list, weights):
            result += weight * params

        return result
```
