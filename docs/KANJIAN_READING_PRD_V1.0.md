## 二、PRD 核心需求清单 (13 大模块)

### 模块 1: 4 端产品结构 (WBS)

| 端 | 角色 | 核心职责 |
|---|---|---|
| **用户端** | 普通会员 / 参与者 | 账号 / AI 辅助 / 活动 / 笔记 / 社群 / 付费 |
| **工具端** | AI 数智体 + 系统底层 | 智能匹配 / 阅读算法 / 数字资产 / 笔记模板 |
| **主理人端** | 核心团队 + 领域带领者 | 去中心化运营 / 内容资源 / 社群氛围 / 数据复盘 |
| **推广人端** | 裂变 / 合作 / 市场 | 拉新 / 活动推广 / B 端合作 / 推广激励 |

### 模块 2: 业务闭环 (10 步用户流)

```
申请参与 → AI 匹配 → 线上打卡+线下交流 → 申请带领者
  → 相互赋能 (欣赏卡/感恩帖) → AI 整理笔记 (数字资产)
  → 会员增值服务 → 文旅跨界 → 口碑裂变 → 社群迭代
```

### 模块 3: 7 级成长体系 (L1-L7)

| 等级 | 名称 | 成长值 | 定位 | 关键权益 |
|---|---|---|---|---|
| L1 | 初见者 | 0-200 | 新用户入门 | 基础账户 / 免费模板 / 公开活动 |
| L2 | 同行者 | 201-800 | 活跃读者 | AI 基础 / 每日打卡 / 笔记导出 |
| L3 | 微光者 | 801-2000 | 深度参与者 | 优先报名 / 专属皮肤 / 社群标签 |
| L4 | 星芒者 | 2001-5000 | 优质分享者 | 申请领读人 / 免费高阶课 1 节/月 |
| L5 | 执灯人 | 5001-12000 | 正式领读人 | 自主开活动 / 收益分成 / 数字资产扩容 |
| L6 | 引路人 | 12001-30000 | 资深主理人 | 企业团建 / IP 包装 / 分站优先 |
| L7 | 共创者 | 30001+ | 核心共建者 | 决策参与 / 分红 / 品牌联名 |

## 五、关键决策点 (等用户确认)

### 决策 1: 项目定位

- **A. Reading-FL 转型** — 同一个产品, 改定位 + 加情感系统
- **B. 姊妹项目** — Reading-FL 是"技术 demo / 学术台", 看见读书会是"商业产品", 共用部分代码
- **C. 独立项目** — 看见读书会完全独立, 跟 Reading-FL 不挂钩
- **D. 暂不动** — 先写 PRD / 销售页 / GTM, 不动代码

### 决策 2: 技术选型

- 复用 Streamlit (快, 受限) / 全新独立产品 (微信小程序 + 知识星球 + 自研) / 最小化 (销售页 + 微信群 + 12 人首期手动)

### 决策 3: 优先级

- 1 天 (1-2 项) / 1 周 (1 个 phase) / 1 月 (走完 1 个完整 phase)
