## 一、12 大启发 (从两份材料原话 → Reading-FL 改造)

### A. 产品哲学 (3 个)

#### 启发 1: 从"段级共鸣"升级到"被看见"

**看见原话**: 「人人被看见、人人被肯定」「找到志同道合的伙伴, 被看见、被记住、不孤独」

**Reading-FL 现状**: 我们卖"段级共鸣 + 跨书匹配" — 是**功能**, 不是**情绪**。

**启发改造**:
- v6.1 把"共鸣" 改名为 **"被看见"**
- 共鸣墙 → **"被看见墙"**
- 主页 hero 不写"段级共鸣社区", 写"你读过的字, 在陌生人那里被看见"
- 数字资产 → **"我的成长纪念"**

#### 启发 2: 从"工具"升级到"仪式感"

**看见原话**: 「开场 5 分钟静心」「书是引子, 安静是结果」「不评判、不比较、不抢话」

**Reading-FL 现状**: 打开 app 就是 list of 摘录, **没有任何仪式感**。

**启发改造**:
- 主页加 **"今日静心 30 秒"** 启动屏 (4-7-8 呼吸 + 暗色过渡)
- 写摘录前先有"此刻, 你要停下来" 引导
- 关闭电脑时弹"今天你被 3 段话打动了"
- 共鸣墙不再是 list, 是 **"夜里 11 点的灯"** 意象 (暗背景 + 暖光晕染)

#### 启发 3: 从"积分激励"升级到"被看见激励"

**看见原话**: 「欣赏卡 6 个暖心标签」「你的分享很治愈 / 思想同频 / 温暖真诚」「被感谢 +20 成长值」

**Reading-FL 现状**: 积分强调动作 (摘录 +5 / 段级被共鸣 +20), **不强调人**。

**启发改造**:
- 加 **"被看见"维度** 独立于积分:
  - 被共鸣 → "**有 X 个段友在这里看到你**" (替代"你 +20 积分")
  - 被感谢 → "**X 个人说你的摘录很治愈**" (替代"你 +50 积分")
- 主页 **"今天, 你被看见了几次?"** 计数
- 加 **"今日被看见"暖心播报**

### B. 核心功能 (3 个)

#### 启发 4: 加"墨韵雅集" — 每周 1 聚

**看见原话**: 「7 大产品模块 - 墨韵雅集 (一周一聚)」「每场线下聚会结束弹窗: 感谢伙伴 / 领读人」

**Reading-FL 现状**: 只有**线上**共鸣墙, **没有任何"集体"仪式**。

**启发改造**:
- 加 `pages/9_gathering.py "墨韵雅集"`:
  - 每周 1 个主题 (从书单 + 用户投票)
  - 虚拟"云聚会" (st.feedback + st.chat_input 共读 1 小时)
  - 结束弹"今天 3 个段友陪你"
  - **不**真做线下 (但留接口)
- 把"段级共鸣" 落地为**"每周固定仪式"**, 用户 LTV 大幅提升

#### 启发 5: 加"片语映见" — 1 段 1 句话

**看见原话**: 「7 大产品模块 - 片语映见 (每人一句摘要)」「思萃撷英」「言启心窗」

**Reading-FL 现状**: 摘录必须输入**完整段**(50-200 字), 门槛高。

**启发改造**:
- 加 **"片语映见"快捷入口**:
  - 截屏识别自动提取"今日打动你的一句话"(只 1 句)
  - 主页加 **"今天一句话"** 1 键输入框
  - 3 秒发布 = "片语"
- 把"段级共鸣" 降维到 **"片级共鸣"**, 发布频次提升 5x

#### 启发 6: 加"私密树洞"

**看见原话**: 「个人私密树洞: 加密日记、仅本人可见、情绪安放、AI 心灵陪伴」

**Reading-FL 现状**: 摘录**全部公开**, 没有"私密"维度。

**启发改造**:
- 加 **"树洞"模式**:
  - 摘录时可勾选"只给自己看" / "只给同 MBTI 看" / "完全公开" 3 档
  - 树洞笔记不进入 FL 训练 (隐私绝对保护)
  - AI 精灵可访问树洞 (心灵陪伴)
- 把"读书" 升级为 **"独处", 满足"自我怀疑"用户**

### C. UX / 文案 (3 个)

#### 启发 7: 改所有 error / 加载 文案为"心灵语气"

**看见原话**: 「"别怕, 有我"」「"我也经历过, 会过去的"」「AI 心灵陪伴」

**Reading-FL 现状**:
- `st.error("❌ AMAX HTTP 401")`
- `st.spinner("段友正在找共鸣...")` (我改的, 算 OK)
- `st.warning("⚠️ 鉴权失败")`

**启发改造**: 全部改"心灵语气":

| 现状 | v6.1 |
|---|---|
| ❌ AMAX HTTP 401 | 🪔 灯暂时暗了一下, 我们再点点看 |
| ⚠️ 鉴权失败 | 🪔 你没设好 AI 钥匙, 我等你 |
| 加载中... | 🪔 段友正在翻书, 等一下下 |
| 未配置... | 🪔 我暂时只能听你说, 不能回答 |

#### 启发 8: 改积分图标 + 名称 + 颜色

**看见原话**: 「手账皮肤 9.9-29.9」「数字资产皮肤」

**Reading-FL 现状**:
- 积分图标: 💡 / 5
- 颜色: 单一金色
- 数字资产: 没有"皮肤" / "封面" 概念

**启发改造**:
- 积分图标: 💡 → 🪔
- 等级 L1-L7 (跟看见对齐): 初见 / 同行 / 微光 / 星芒 / 执灯 / 引路 / 共创
- 数字资产**可换封面** (3-5 个暖色主题: 夜读 / 晨曦 / 烛光 / 园林 / 雪山)
- **9.9 元/款皮肤** — 极小商业化, 用户"个性化"

#### 启发 9: 加"我的年度轨迹" 视频导出

**看见原话**: 「年度 Retreat 帮助用户跳出来看自己一整年」「可二次加工为个人阅读图册、文创作品」

**Reading-FL 现状**:
- 数字资产 (pages/3_archive) 有
- **没有年度汇总 / 视频导出**

**启发改造**:
- 加 `pages/9_year.py "我的年度灯"`:
  - 12 月月历 (暖光 = 该月写了摘录)
  - "2026 年你写了 47 段, 被打动 23 次, 引发 8 个段友共鸣"
  - **可导出 PDF / 短视频** (1 分钟暗色动画)
- 把"数据" 变 **"礼物"**, 用户主动发朋友圈 = 0 成本裂变

### D. 商业 / 留存 (2 个)

#### 启发 10: 改免费 + 增值 双层模式

**看见原话**: 「基础免费 + 会员 2999/5999/9999」「手账 9.9-29.9」「续费 +20%」

**Reading-FL 现状**: 完全免费, **没有任何 C 端商业化路径**。

**启发改造**:
- v6.1 加**双层模式**:
  - **基础免费**: 写摘录 / 被看见墙 / 我的书灯 / 段友推荐
  - **会员 ¥99/年** (看见的 1/30, 中国读书心理价位):
    - 高级 AI 精灵 (心灵语气, 长对话)
    - 跨书情感图谱 (个人成长曲线)
    - 数字资产皮肤 12 款
    - 墨韵雅集 优先报名
    - 年度灯 PDF 导出
- **不收 2999-9999** (那是 8-12 人高端社群价位, Reading-FL 是 万人轻量产品)

#### 启发 11: 加"领读人" / "主理人" 5 级身份

**看见原话**: 「L5 执灯人 = 正式领读人」「L6 引路人 = 资深主理人」「L7 共创者 = 核心共建者」

**Reading-FL 现状**:
- 我们的"坐忘·见" 是**网文作者 dashboard** (作者视角)
- 没有**用户自荐**做领读人 / 主理人 的通道

**启发改造**:
- 把"坐忘·见" 改名为 **"执灯人"**
- 加 **"申请成为执灯人"** 流程:
  - L3+ 用户可申请
  - 提交: 1 段原创领读 + 1 段书单推荐
  - 审核通过 = 升级 L4 (星芒者)
  - 可发起 **"我的雅集"** (L4+ 专属)
- 把"网文作者" 升级为 **"全民领读人"**, 激活供给侧

### E. 技术 / 工程 (1 个)

#### 启发 12: 加"小而稳"的反脆弱设计

**看见原话**: 「AI 鉴权失败: 我暂时只能听你说」「AMAX 失败: 灯暂时暗了一下」「筛选机制: 进来的人, 都是同类」

**Reading-FL 现状**:
- AMAX 失败时, 我们的 fallback 是"诚实地回" (v6 精灵改进) — 但**所有页面**没统一的 fallback
- 没有"用户筛选"机制, 任何人都能注册

**启发改造**:
- v6.1 加 **统一降级策略**:
  - 所有 AI 调用 → 失败时显示"灯暂时暗了, 我再点点"
  - 所有加载 → 超过 3s → "等久了? 试试刷新"
  - 所有异常 → "你遇到一个 bug, 我们记下了, 请发到 x@y.com"
- 加 **"段友筛选"**:
  - 首次注册 → 1 分钟问卷: "你读什么 / 你想要什么 / 你的痛点"
  - 强制: 选 ≥3 个情感标签
  - 天然抗 spam + 天然画像 (FL 训练数据更干净)
  - 类似看见"只招已婚已育女性" — 但我们更宽: "任何想被看见的人"
