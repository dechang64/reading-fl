## 3. v6.3 心动林音乐 spec

### 3.1 触发

| 场景 | 行为 | 播放 |
|---|---|---|
| 进入心动林页 | 不自动播 | 静默 |
| 用户滚到某段卡 (e.g. 3 张示例卡) | 卡片右下角 🎵 按钮显示 | 不自动 |
| 用户点 🎵 按钮 | 调 MiniMax music API, 生成 30s | 播 30s loop |
| 卡片切换到下一段 | 上一个 30s 自然结束 | 新段卡 🎵 出现 |
| 再次点 🎵 | 切到新音频 | 覆盖当前 |

### 3.2 提示词模板

```python
full_prompt = "中国传统乐器演奏的{emotion_cn}氛围音乐, 《{book}》{chapter}的氛围, 空灵悠远, 30秒, 适合冥想"
```

**示例**:
```
中国传统乐器演奏的思考氛围音乐, 《代码乡愁》第3章的氛围, 空灵悠远, 30秒, 适合冥想
```

**与 dgy-treehole 区别**:
- dgy-treehole: 9 大观园场景 × 6 情绪 = 54 段
- Reading-FL: N 本书 × 6 情绪 = N×6 段 (按 book+emotion 缓存)

### 3.3 API 调用

**复用 dgy-treehole `core/minimax_music.py`** → 复制为 `core/amax_music.py`

```python
def generate_ambient_music(
    emotion: str,           # 6 维: 感动/思考/共鸣/困惑/反对/平静
    book: str,              # 书名 (e.g. "代码乡愁")
    chapter: str = "",      # 章节 (e.g. "第 3 章")
    duration: int = 30,     # 秒
) -> str | None:
    """返回音频 URL (或本地文件路径)"""
    # 调 MiniMax music-2.6 API
    # 缓存: hash(emotion + book) → 复用
```

### 3.4 缓存机制

```python
# st.session_state.music_cache: {hash: audio_url}
# 首次生成 → setItem 持久化到 localStorage
# 二次访问 → 直接用缓存
# 30s 音频 (1-2 MB) → 5 本书 × 6 情绪 = 60 个 → ~100 MB localStorage 上限风险
# 解决: 缓存到 streamlit server (DB / file) + 浏览器只存 hash
```

### 3.5 UI 改动 (心动林 2_resonance.py)

```python
# 每张共鸣卡底部
for r in rows:
    st.html(f"""
    <div class="resonance-row">

        </div>
        <button class="play-btn" data-eid="{r['id']}">🎵 听 30s</button>
    </div>
    """)
```

### 3.6 隐私

- 音频**不存用户文本**, 只存 hash(book+chapter+emotion)
- 音频 URL 来自 MiniMax API, 24h 过期 → 不持久

## 8. v6.3.1 姊妹特性: AI 金句 (5 种输入方式)

User: "用户让大模型生成一段金句作为输入呢? (目前已有四种方式)"

### 8.1 5 种输入方式对比

| 方式 | 现状 | 输入 | 输出 |
|---|---|---|---|
| 1. ✍️ 打字 | ✅ | 用户**已有** | 录入加速 |
| 2. 📷 拍照 | ✅ | 纸书**已有** | 录入加速 |
| 3. 🖼 上传图 | ✅ | 截图**已有** | 录入加速 |
| 4. 🎙 语音 | ✅ | 用户**口述** | 录入加速 |
| **5. 🤖 AI 金句** | ❌ (新) | **没有**, 但**想要** | **创作加速** |

**核心价值**: 大部分用户读完就忘, 因为**不知道该记什么**. AI 给 3 段选 1, 降低写摘录门槛.

### 8.2 输入

| 选书 (e.g. "《三体》" / "任何") | ✅ | "《三体》" |
| 主题 (一句话) | ✅ | "宇宙的孤独感" |
| 风格 (鲁迅/海明威/...) | 可选 | "鲁迅" |
| 情绪 (感动/共鸣/...) | 可选 | "共鸣" |
| 数量 | 1-5 | 3 |
