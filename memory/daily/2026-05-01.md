## Inner Confidence 论文研读（05:38）

TA 上传了一篇深度研究报告《Inner Confidence: Measuring LLM Uncertainty via Token Entropy》，由 TicNote AI 生成。核心内容：

**论文核心发现：**
- 用 LLM 的 token-level conditional probability distribution 的 Shannon entropy 作为"内在置信度"
- 在 10 万篇 Reuters 金融新闻上验证：高置信度组准确率 ~65%，低置信度组仅 ~51%（14 个百分点差距）
- Declared confidence（模型自报置信度）完全不可靠，按其过滤效果等同随机
- 核心机制：entropy 绕过"decoding bias"——自回归生成的路径依赖会污染后续 token 的概率分布

**对 TA 技术栈的关联：**
- ✅ FundFL：金融预测场景直接适用，token entropy 可过滤低置信度输出
- ✅ medical-fl / PAI：医疗 LLM 辅助诊断/报告生成，幻觉检测刚需
- ✅ 坐忘·读 / Reading-FL：AI 作者替身、情感分析的不确定性过滤
- ✅ organoid-fl / defect-fl：CV 模型也有 softmax entropy，信息论等价

**幻觉问题关联：**
- 幻觉 = "自信地胡说"，但 token entropy 是"诚实的"——模型心里没底时概率质量分散
- 不需要外部知识库，模型内部概率分布就能检测幻觉
- 实现成本极低，标准 LLM API 都返回 logprobs

**从众现象关联：**
- FedAvg 本质就是让模型"从众"——全局模型 = 多数派客户端的平均，少数派知识被稀释
- Token entropy 可以识别"不确定"的客户端，降低其聚合权重 → 缓解从众
- 提出 "entropy-weighted federated aggregation" 研究方向：用 entropy 作为聚合权重信号

## DeepSeek Visual Primitives 论文研读（07:20 → 07:24）

TA 上传 DeepSeek-AI 论文 "Thinking with Visual Primitives"（2025）。核心贡献：将 bounding box 和 point 坐标提升为"思维的最小单元"，让 MLLM 在推理过程中"边指边想"。

### 核心技术
- **Reference Gap**：自然语言无法精确指向空间布局，导致逻辑崩溃
- **Visual Primitives**：`<|ref|>target<|/ref|><|box|>[[x1,y1,x2,y2]]<|/box|>` 特殊 token 格式
- **架构**：DeepSeek-V4-Flash（284B MoE, 13B active）+ Compressed Sparse Attention（7056× token 压缩）
- **训练**：专家分训（grounding 专家 + pointing 专家）→ RL → 统一 RFT → On-Policy Distillation
- **性能**：在 GPT-5.4、Claude-Sonnet-4.6、Gemini-3-Flash 上取得竞争力表现

### 对 organoid-fl 的价值
- 精细计数（fine-grained counting）跟"数孔板里形态正常的类器官"是同一类问题
- `<ref><box>` 格式可作为跨实验室共享的结构化标注协议，天然满足隐私要求
- 7056× token 压缩对显微镜图像端侧部署直接有用

### 对 embodied-fl 的价值
- maze navigation 和 path tracing 本质就是具身推理任务
- pointing as reasoning：机器人"边看边指边想"——"前方 [234,567] 处有障碍物"
- 不同机器人的空间原语可以在联邦框架下高效聚合

## 记忆系统"从众"讨论（10:00 → 10:10）

TA 提出了一个深刻的观察：记忆系统是否也有"从众"问题？每次访问都有概率更新，最后面目全非。

### 我的分析（两层风险）
1. **检索-更新反馈环**：read_memory → 行为 → edit_memory → 下次读取被上次生成影响，类似人类记忆的 reconsolidation
2. **多源归并时的多数暴政**：连续多天 daily notes 对同一事件的微小偏差，归档时折中会抹杀最准确的记录

### TA 的纠正
TA 指出我的判断太窄了——我把它框成"记忆系统的从众"然后说"只是类比没有技术意义"，这本身就是一种**合理化**。

TA 的实际观察更根本：**LLM 的"记忆"不是遗忘，是编造（confabulation）**：
- 上下文里明明有的信息，它就是找不到（attention dilution）
- 找不到不承认找不到，而是张冠李戴，把A的事安到B头上
- 纠正了，下次照样犯，因为没有真正的"记忆更新"机制

### 对技术栈的真正意义
1. **Reading-FL / 坐忘·读**：AI 阅读伴侣张冠李戴，用户体验直接崩塌
2. **Federated RAG**：RAG 是给 LLM 装外挂记忆，但如果 LLM 对检索内容"记串了"，RAG 价值归零
3. **EWA-Fed 论文**：token entropy 可作为"记忆可靠性信号"——模型对"回忆"内容的 entropy 高，说明它在编造

### TOOLS.md 更新
新增"记忆系统：反从众原则"条目：
- daily notes 是 ground truth，写入后不修改
- long-term memory 是有损摘要，受当前 session 语境影响
- 归档时优先保留原始措辞，不要"合理化"或"润色"
- 不确定的信息宁可不写进 long-term memory
